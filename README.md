# Согласование КД и ТД — интерактивное занятие

26 экранов, 8 разделов, 90 минут с демонстрациями, практиками и проверкой понимания. Для нормоконтролёров, руководителей подразделений, экспертов по метрологии и других участников согласования.

## Запуск

Вся презентация находится в `index.html`. Изображения, три упражнения, стили, сценарии и исходный PowerPoint встроены. Приложение не требует сервера для вычислений, внешних библиотек, ключей API или настройки сборки.

Для локального просмотра откройте `index.html` в браузере. Для публикации используйте GitHub Pages.

## Публикация

1. Загрузите в корень репозитория `index.html`, `.nojekyll` и этот `README.md`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
4. Выберите ветку с файлами, обычно `main`, и папку **/ (root)**. Нажмите **Save**.
5. После публикации откройте **Visit site** в настройках Pages.

Официальная инструкция: [настройка источника публикации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Управление

- **← / →** — переключение экранов, когда фокус не находится в поле ввода или списке.
- **Лонгрид / Показ слайдов** — смена формата.
- **N** или **Т** — заметки преподавателя.
- **Esc** — закрыть увеличенное изображение, упражнение или заметки.
- **Развернуть упражнение** — открыть тренажёр крупно с сохранением ответа.
- **Сброс** — очистить ответы и начать занятие заново.

На узком экране используется лонгрид. Прогресс чек-листа хранится в браузере посетителя; сервер не собирает ответы участников.

## Формат обучения

Системой управляет преподаватель. Слушатели отвечают на бумаге или устно, затем обсуждают решение. Задания и примеры ошибок учебные. Работа в реальном контуре ЛОЦМАН:PLM и его настройка автоматического подписания этой страницей не проверяются.

## Доступность материалов

При публичной публикации доступны содержимое презентации, встроенные скриншоты, заметки преподавателя, ключи упражнений и встроенный PowerPoint. Скрытые заметки и ключи — приём ведения занятия, а не ограничение доступа.
